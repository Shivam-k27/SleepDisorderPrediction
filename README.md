# Sleep Disorder Prediction Web Application

A machine learning-powered web application that predicts potential sleep disorders based on an individual's lifestyle, health, and physiological attributes. Built using Flask and Scikit-learn, the application provides real-time predictions through an intuitive and responsive user interface.

---

## 📌 Project Overview

Sleep disorders significantly impact overall health, productivity, and quality of life. This project leverages machine learning techniques to analyze user-provided health and lifestyle metrics and predict the likelihood of sleep-related disorders.

The application allows users to input demographic, occupational, and health-related information through a web interface and instantly receive a prediction generated by a trained machine learning model.

---

## 🚀 Key Features

* Interactive and user-friendly web interface
* Real-time sleep disorder prediction
* Machine Learning model integrated with Flask
* Support for multiple occupation categories

## 📊 Input Parameters

The model analyzes the following features:

* Age
* Gender
* Occupation
* Sleep Duration
* Quality of Sleep
* Physical Activity Level
* Stress Level
* BMI Category
* Heart Rate
* Daily Steps
* Blood Pressure

## 📈 Application Workflow

1. User enters health and lifestyle information.
2. Input data is preprocessed and formatted.
3. Trained machine learning model performs inference.
4. Prediction is generated and displayed on the web interface.
5. User receives instant feedback regarding potential sleep disorders.
